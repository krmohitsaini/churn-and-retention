# Sample Data Schema

Put replacement dummy data in this folder using the same file names, or update the repository methods in `backend/app/data/csv_repository.py` if your names differ.

## customers.csv

Customer portfolio snapshot. One row per customer.

## churn_events.csv

Historical churn events. One row per churn event.

## propensity_scores.csv

Precomputed customer churn propensity output. One row per scored customer.

## customer_interactions.csv

Customer service, billing, sales, and digital interactions.

## offers.csv

Retention offers and actions that may be recommended to customers.
